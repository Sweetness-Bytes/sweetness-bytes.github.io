# Sweetness — Homemade Chocolates

Website for **Sweetness**, homemade chocolates from Malad East, Mumbai.

Live site: https://sweetness-bytes.github.io

- Single-file site (`index.html`) — all images are embedded, no build step.
- Orders go to WhatsApp (+91 93210 41941); payment via UPI (kirangarate44@oksbi).
- To update chocolate prices or items, edit the `MENU` list inside `index.html`.
- IZYAN Attar & Perfumes: product data is the `IZ` list in `index.html` (12 ml attar = PDF price + 10%, 50 ml perfume = attar price + Rs 150); photos are in `izyan/`.
